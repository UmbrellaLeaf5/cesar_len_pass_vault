## UI.3 - Режим просмотра (Show/Hide паролей)

**Что сделать:**

- Кнопка **hide** / **show** на тулбаре Vault Screen
- При нажатии все поля `password` в JSON-редакторе заменяются на `***` (скрыто) или показываются обратно (раскрыто)

**Реализация:**

- Тулбар: добавить кнопки `hide` / `show` (меняются местами по toggle)
- Скрытие: `re.sub(r'"password":\s*"[^"]*"', '"password": "***"', editor.text)` - прячет пароли в отображаемом JSON
- Показ: восстанавливает оригинальный JSON из скрытой копии (хранить `_original_json` в атрибуте экрана)

**Сложность:** низкая

- ~15 строк Python в `vault.py` + 2 кнопки в тулбаре

## Безопасность.1 - Генератор паролей

**Что сделать:**

- Маленькая квадратная кнопка **gen** справа от поля `password` в `AddEntryPopup`
- При нажатии - генерирует случайный пароль и вставляет в поле
- Параметры генерации (длина, спецсимволы) - можно захардкодить или добавить мини-настройки

**Параметры по умолчанию:**

- Длина: 20 символов
- Состав: буквы (верхний + нижний регистр), цифры, спецсимволы (`!@#$%^&*()-_=+`)
- Использовать `secrets.choice()` (криптографически безопасный)

**Реализация:**

- Функция `generate_password(length=20, use_special=True) -> str` в `app/utils.py`
- Кнопка в `AddEntryPopup` на том же уровне, что и `password_input`
- При клике - `self.password_input.text = generate_password()`

**Сложность:** низкая

- ~20 строк Python + 1 кнопка в `.kv`
- `secrets` - stdlib, никаких зависимостей

## Безопасность.6 - Смена мастер-пароля

**Что сделать:**

- Отдельный попап `ChangePasswordPopup`
- Поля: `current_password`, `new_password`, `confirm_new_password`
- Логика:
  1. Проверить текущий пароль (попробовать расшифровать vault)
  2. Перешифровать оба хранилища (primary + backup) новым паролем
  3. Загрузить на Yandex Disk
  4. Обновить in-memory мастер-пароль в приложении

**Реализация:**

- Новый файл `app/popups/change_password.py` + `.kv`
- Сервисная функция в `app/services/vault_ops.py`: `change_password(old_pw, new_pw) -> None`
- Кнопка в `SettingsPopup` → открывает `ChangePasswordPopup`

**Сложность:** средняя-высокая

- Нужно корректно обработать оба хранилища (primary + backup)
- Риск потери данных при ошибке - нужна транзакционность (сначала загрузить новое, потом старое)
- Обновить `app.master_password` после успешной смены
- Обработка ошибок сети и неверного текущего пароля
